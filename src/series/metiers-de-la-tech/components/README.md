# `metiers-de-la-tech/components`

Composants **spécifiques à la série** `metiers-de-la-tech` : cartes métier,
badges de salaire, graphiques de secteurs, etc.

Règle de placement :

- le composant ne sert qu'à cette série → ici ;
- le composant peut servir à d'autres séries → `src/components/`.

Les composants de ce dossier doivent réutiliser la configuration de
`src/config` (couleurs, typographies, espacements) et ne jamais hardcoder
une valeur de la DA. Voir docs/RULES.md.
